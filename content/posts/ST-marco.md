## ☘️：酒馆自带宏有哪些？

酒馆出厂就自带着一些宏，最常见的有：

>▪`{{user}}`👉🏻你的用户名（比如"小灰"）
>
>▪`{{char}}`👉🏻当前角色的名字（比如"Rinn"）
>
>▪`{{time}}`👉🏻现在几点
>
>▪`{{date}}`👉🏻今天几号

这些都是酒馆自己的崽。但酒馆自带的宏就那么几个，有时候你想要一些酒馆没有的功能，比如：

>🌰：想在聊天中发个表情包，于是打出：`https://xxxxx.jpg`，试图让它发出去就自动变成表情包

but酒馆并不认识 "`https://xxxxx.jpg`" 这个东西😱!!它只认识自己亲生的（`{{user}}`、`{{char}}`这些玩意……

这时候就需要告诉酒馆：

>"把`https://xxxxx.jpg` 给我变成 "表情包.jpg"，懂？😎"

👆🏻这个"告诉酒馆"的过程，就叫做【注册宏】啦！( ´▽` )

## ☘️使用【酒馆助手】插件
将==【https://xxxxxxx.jpg】==这串玩意儿注册为`{{img::meme}}`
宏的名字随便你定啦！。还可以按类别场景来分组起名，比如背景图一组、差分表情一组、UI素材一组……或者注册不同前缀的宏（`{{bg::xxx}}`、`{{expression::xxx}}`、`{{ui::xxx}}`），这样AI用着语义也会清晰点呢w

注册完就是酒馆的崽。只不过自带宏是酒馆亲生的，`{{img::meme}}` 是你自己领养的罢了。用起来完全无差:3

## ☘️：注册完了如何正确使用？

注册完之后，在角色卡的任何地方加 `{{img::meme}}`的话，酒馆在把消息发给AI之前就会把这个宏成那个表情包的url！
所以，AI看到的不是 `{{img::meme}}`，ta看到的会是一个正常的url网址

在HTML代码里用也一样，如：

```

background-image: url('{{img::meme}}');

```

酒馆先把 `{{img::meme}} `换成网址，这段代码再被插件渲染。最终前端的视觉效果就是：看到了一张表情包

## ❓如何使用【酒馆助手】插件注册宏：

酒馆助手提供了一个功能叫做=="registerMacroLike"==，在插件的==【脚本库】==里塞行代码就能注册


### 🧀一、传图拿图

* 首先你需要一张图片的URL。
个人推荐Postimg，下面示例均使用此网站

[🩷Postimages（点我！）](https:/postimages.org/)

* ①上传图片。

![上传图片](/images/04.13-1.jpg)

* ②复制【直达链接】。这个链接就是URL地址。

![复制直达链接](/images/04.13-2.jpg)

这样你就拿到这张图的URL了！


### 🧀二、复制粘贴环节……

* 🩷要用到的代码长这样：

```

registerMacroLike(

  /\{\{【☘️这里填宏的名字】\}\}/g,

  (context, substring) => {

    return '【☘️这里填你的URL地址】';

  }

);

```

* ②别担心！标注了==【☘️注释处】==的地方直接整个替换成你的图片url地址就可以了

🌰：

```

registerMacroLike(

  /\{\{img::kairin\}\}/g,

  (context, substring) => {

    return 'https://i.postimg.cc/pybVLzHs/1769855708353.png';

  }

);

```

#### ☘️：如果有很多张图呢？

不用一张图开一条脚本！可以一次性注册一串：

```

registerMacroLike(

  /\{\{img::(\w+)\}\}/g,

  (context, substring, key) => {

    const images = {

      '【☘️宏名，下同】':     'https://【☘️URL，下同】',

      '【🍥】': 'https://【🍥】',

      '【🌷】':  'https://【🌷】',

    };

    return images[key] || '';

  }

);

```

*加图直接跟大部队保持队形走就行*

### 🧀好处：

* 超干净 —— 直接塞URL又臭又长还占token！

* 通用 —— 宏是插件级别，不管开哪个角色卡、哪个世界观都能用同一套图片资源

* 模型注意力成本极低 —— 它只需要知道用 `{{名字}} `就好，比记住URL简单稳定多了
