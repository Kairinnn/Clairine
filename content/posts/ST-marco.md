# 酒馆宏是什么？给完全不懂的猪猪解释！



## 先说最基本的：==宏是啥==



### >☘️：在酒馆输入框内打字时，某些特殊写法在发送出去之后酒馆会自动帮你替换成其他的玩意儿。

👌🏻就这么简单。Almost like自动替换



* 🌰：当你在角色卡里写了一句话：



>『`{{user}}`，早上好。』



你的用户角色名叫【小灰】。那么当酒馆发给AI的时候，AI看到的就是：



>『小灰，早上好。』



酒馆当中间人，把`{{user}}`换成你的名字。你啥都不用做。



这个`{{user}}`就叫==【宏】==



* 前端发：`{{user}}`→🧀酒馆换→后端看到：小灰

* 后端发：`{{user}}`→🧀酒馆换→前端看到：小灰

约等于占位符。发出去，酒馆换。完结撒花🎉🎉



### >☘️：为什么要用宏？直接写名不就行了吗？



行啊！当然可以直接写【小灰】

但是。

* 假设你换了个user，ta叫【灰小】捏？那你就得把所有有关【小灰】的宏全手动改成【灰小】，漏一个就露馅。



如果用宏呢？啥都不用改。`{{user}}` 永远会变成当前user的名字，user叫啥它是啥。



#### 所以宏的好处：==『注册一次，终生受益。』==



### >☘️：酒馆自带宏有哪些？



酒馆出厂就自带着一些宏，最常用的有：



▪`{{user}}`👉🏻你的用户名（比如"小灰"）

▪`{{char}}`👉🏻当前角色的名字（比如"Rinn"）

▪`{{time}}`👉🏻现在几点

▪`{{date}}`👉🏻今天几号

这些都是酒馆自己的崽。

但酒馆自带的宏就那么几个，有时候你想要一些酒馆没有的功能，比如：



>🌰：想在聊天中发个表情包，于是打出：`https://i.postimg.cc/9Q8Tx43f/Image-1772173361197-489.jpg`，试图让它发出去就会自动变成表情包



but酒馆并不认识 "`https://i.postimg.cc/9Q8Tx43f/Image-1772173361197-489.jpg`" 这个东西啊！！😱它只认识自己亲生的（`{{user}}`、`{{char}}`之类）



这时候就需要跟酒馆说：



>"把`https://i.postimg.cc/9Q8Tx43f/Image-1772173361197-489.jpg` 给我自动变成 "表情包.jpg"，懂？"



👆🏻这个"告诉酒馆"的过程，就叫做【注册宏】( ´▽` )



### ☘️使用【酒馆助手】插件将【`https://xxxxxxx.jpg`】

这串玩意注册为`{{img::meme}}`，

这个名字随便你定啦！。还可以按类别场景来分组起名，比如背景图一组、差分表情一组、UI素材一组……或者注册不同前缀的宏（`{{bg::xxx}}`、`{{expression::xxx}}`、`{{ui::xxx}}`），这样AI用着语义也清晰点。



注册完之后，发上去酒馆照样自动帮你换。只不过自带宏是酒馆亲生的，`{{img::meme}}` 是你自己领养的罢了。用起来完全无差



### ☘️：注册完了怎么用？



注册完之后，你在角色卡的任何地方写 `{{img::meme}}`，酒馆发给AI之前就会把它换成那个表情包的url。

AI看到的不是 `{{img::meme}}`，ta看到的只是一个正常url网址。



在HTML代码里用也一样，比如：

```

background-image: url('{{img::meme}}');

```



酒馆先把 `{{img::meme}} `换成真实网址，然后这段代码再被插件渲染。最终视觉效果就是：你看到了一张表情包。

### ❓如何使用【酒馆助手】插件注册宏：

酒馆助手提供了一个功能叫做"registerMacroLike"，在插件的【脚本库】功能块里塞行代码就能注册



### 🧀一、传图拿图

* 首先你需要一张图片的URL。

个人推荐Postimg，下面示例均使用此网站

https://postimages.org/


* ①上传图片。

![格式任意](/images/04.13-1.jpg)

* ②复制【直达链接】。这个链接就是URL地址。

![这样你就拿到这张图的URL了！](/images/04.13-2.jpg)



### 🧀二、复制粘贴……

* 🩷代码长这样：

```

registerMacroLike(

  /\{\{【☘️这里填宏的名字】\}\}/g,

  (context, substring) => {

    return '【☘️这里填你的URL地址】';

  }

);

```

* ②别怕，【注释处】直接整个替换成你的图片url地址就可以了

🌰：

```

registerMacroLike(

  /\{\{img::kairin\}\}/g,

  (context, substring) => {

    return 'https://i.postimg.cc/pybVLzHs/1769855708353.png';

  }

);

```

* ③👆🏻现在我们得到了这串玩意，首先打开脚本库👇🏻：

![按要使用的场景设置类型](/images/04.13-3.jpg)

* ④代码塞进去，随便取个方便你管理的名，保存。

![Done。](/images/04.13-4.jpg)


* ⑤领养完孩子还要记得跟AI说！！

在角色卡/提示词/世界书内主动标上可被引用的宏，提醒AI

🌰（scene：rp使用－角色卡）：



>## 可用图片宏/n
在HTML中如需引用图片，可以使用以下宏名！在前端会自动替成实际URL/n
非必须引用，视场景和上下文决定～（但还是挺希望鼠用的）：/n
背景图：
- `{{img::strawberry}}`：草莓波点背景图－1500x1688px/n
- `{{img::sea}}`：海洋/海边场景－3840x3840px/n/n
<char>表情差分：
- `{{expression::doubt}}` → 疑惑－1080x1080px/n
- `{{expression::helpless}}` → 无奈－1080x1080px/n/n
（ps：详细应用方式请见<marco_reference>）

*👆🏻注意‼️这段提示仅适用于我预设的html规范，其他预设如果提示词里没教怎么使，模型很可能只会平铺。

- 最好标注上px！这样不容易出错

- 头像图的差分尽量与原图保持同样大小。可以不标注px毕竟是头图

- 如果很想看某个图片被应用在html里的话不如在输入时主动告诉ai让它专门生一个，而不是一直等到随机哪一轮roll出来*

### ☘️：如果有很多张图呢？

不用一张图开一条脚本喔！可以一次性注册一串：

```

registerMacroLike(

  /\{\{img::(\w+)\}\}/g,

  (context, substring, key) => {

    const images = {

      '【☘️宏名，下同】':     'https://【☘️URL，下同】',

      '【🍥】': 'https://【🍥】',

      '【🌷】':  'https://【🌷】',

    };

    return images[key] || '';

  }

);

```

*加图直接跟大部队保持队形走就行*

### 🧀好处：

* 超干净 —— 直接塞URL又臭又长还占token

* 超方便 —— 以后想换张图？

①【推荐】直接在postimg图库中替换对应图片

②改插件脚本里宏对应的URL



两个方法都挺简单的，个人更推荐在postimg直接换。不用动脑（如果不介意名字还是之前那个的话。）

* 通用 —— 宏是插件级的，不管开哪个角色卡、哪个世界观都能用同一套图片资源

* 模型注意力成本极低 —— 它只需要知道用 "{{名字}} "就行，比记住URL简单稳定万倍。
